Qué hace esta web con los datos

La web es estática. No tiene cuentas, formularios, boletines, pagos ni un servidor propio. No usa localStorage ni sessionStorage.

La única cookie propia es lia_consent. Guarda la decisión sobre cookies, la versión del aviso y la fecha, durante 12 meses. No incluye nombre, email ni un identificador de analítica. El detalle está en la política de cookies.

No se piden nombre, email ni ningún otro dato a través de la página. El contacto previsto es un enlace a Instagram y un enlace de correo electrónico.

Alojamiento

El sitio está preparado para publicarse en GitHub Pages. Ese servicio puede tratar datos técnicos de la conexión, como la dirección IP o el identificador del navegador, en registros del propio proveedor. Esta web no recibe esos registros y no los utiliza para analítica.

La política de privacidad de GitHub describe ese tratamiento: declaración de privacidad de GitHub (se abre en una pestaña nueva). El papel exacto de GitHub como encargado, y si hay transferencias fuera del Espacio Económico Europeo, debe confirmarse al cerrar la titularidad y el alojamiento real. No se afirma aquí que existan cláusulas contractuales concretas si no se han revisado.
